# Desk Lock (working name)

An iPhone focus blocker that works like Brick. You tap the NFC sticker on your desk to start a focus session and tap it again to end it. While a session runs, the apps you picked are blocked.

It also includes:
- 5-minute emergency passes
- night lock with tag-to-dismiss alarms
- screen time and focus stats
- an accountability partner

- [docs/design.md](docs/design.md): the app design and build plan
- [docs/research.md](docs/research.md): research on existing open-source blockers, iOS Screen Time and Core NFC, AlarmKit, and NFC tag types
